This patch makes the D110_M's factory reset clear its saved roll history. Reset the NFC sticker's counter separately to reuse a compatible replacement reel.

## Downloads

- **D110_M_V4.31_history-reset.bin**: the complete, headered Bluetooth update image. Select this file in the flasher.
- **SHA256SUMS.txt**: the SHA-256 checksum for the firmware attached to this release.

Download both assets into the same folder. On macOS, verify with:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

Expected firmware SHA-256:

```text
909fe39cf7176e54999fb5a113f94c6792d503b9578362a1a79e00200564ecc8
```

## Compatibility and validation

For **D110_M, model ID 2320**, based on firmware **4.31**. Tested on one printer with hardware **4.01**. **D110 is a different model.** The printer still reports firmware 4.31 after installation; r1 identifies this patch release, not a new device firmware version.

This is the same firmware binary previously verified and published in commit `5fc97f4`. All 21 offline checks passed. Physical Bluetooth flashing, history clearing across a power cycle, and a clear replacement-reel test print were verified. The counter advanced from 0 to 1 after the test print.

The patch clears all remembered rolls when factory reset runs and retains the normal factory-default changes. It does not reset the NFC sticker, disable NFC authentication, or remove label limits. There is no need to reflash for each refill.

This is unofficial firmware. Compatibility beyond the tested hardware is unverified; a failed update may prevent booting, and Bluetooth recovery is not guaranteed. The original image remains in the repository for comparison and possible restoration, but is not a full-device backup or guaranteed recovery image.
